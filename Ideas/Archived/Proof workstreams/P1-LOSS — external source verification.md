# P1-LOSS — external source verification

## Method note (read before trusting any cell below)

Two evidentiary channels were used, and they are **not equally strong**; the table marks which channel backs each cell.

- **[SCITE]** — `mcp__Scite__search_literature` returned `fulltextExcerpts`, i.e. actual indexed passages from the paper's own full text (open-access), plus `citations` snippets that are text drawn from the source paper itself as it cites other work. These are genuine primary-text quotations, not model paraphrase. This is the strongest evidence in this dossier.
- **[WEBFETCH]** — `WebFetch` retrieves the live PDF/HTML and runs a small summarization model over it before returning a result. This is *not* raw text — it is a model's report of what the document says. Every WEBFETCH-sourced claim below was **cross-checked against a second, independently-hosted copy of the same document** before being trusted, and one real discrepancy was caught this way (see Item 1: WebFetch twice mis-numbered the main characterization result as "Proposition 2"; the Scite full-text excerpt proved it is **Proposition 1**, with Proposition 2 being the separate MSE-only special case). Where WEBFETCH claims could not be cross-checked against a second source or against Scite, that is flagged explicitly.
- Journal-of-record paywalls (ScienceDirect/Elsevier for Items 1–2, JSTOR/Taylor & Francis for Items 3–4) were hit and blocked full retrieval directly from the publisher in every case; all full-text verification below came from open-access working-paper mirrors or the arXiv preprint, cross-checked against Scite's index of the published version where possible.
- No raw PDF could be downloaded into this container (outbound curl to arbitrary hosts is blocked by org egress policy); all fetching was done via the WebFetch and Scite tools.
